# Enterprise-Operations-Platform-.Net-Core-MVC-
A secure, layered ASP.NET Core MVC web application designed to modernise healthcare compliance and support staff administration across multi-provincial systems.

An enterprise-grade, secure, and scalable web-based staff management system designed to meet strict modern healthcare compliance frameworks across multi-provincial networks.

---

## Context

Due to recent expansions within the health care system, the organisation faces strict compliance expectations and audit requirements. Managing support staff distributed across multiple provinces has introduced structural challenges.

### Current Internal Administration Weaknesses:
1. **Fragmented Records:** Staff data is maintained using disjointed spreadsheets, desktop tools, and disparate internal applications.
2. **Legacy System Vulnerabilities:**
   * **Weak Access Control:** Inadequate role-based permissions create security risks.
   * **Limited Scalability:** Current setups cannot support organizational growth across regions.
   * **Inconsistent Data:** Siloed tracking creates single points of truth friction and mismatched staff data.
   * **Legacy Technical Debt:** Poor readiness for secure, modern cloud-based integration.

---

## Proposed Solution: ESOP Initiative

The **Enterprise Staff Operations Platform (ESOP)** initiative modernises internal administrative workflows, bringing them in line with enterprise software development practices and modern build standards.

### Core Objective
To deploy a **secure, scalable, and web-based Staff Management system** that unifies multi-provincial data under uniform compliance controls.

### Technical System Requirements
*  **Admin-Only Access Enforcement:** Strict authentication structures to block unauthorized endpoints.
*  **Full Staff CRUD Functionality:** Standardised workflows to Create, Read, Update, and Delete workforce records safely.
*  **Layered Architecture:** Segregation of concerns implemented through **Models, Services, Controllers, and Views (MSCV)**.
*  **In-Memory Storage:** Decoupled, database-ready initial state using modern .NET dependency injection.
*  **Modern .NET Tooling:** Built using production-ready testing tools, static analysis, and code quality workflows.
